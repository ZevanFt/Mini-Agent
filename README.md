## 🚀 快速开始

### 使用方式

| 场景 | 命令 |
|------|------|
| **不安装直接用** | `npx miniagent chat` |
| **全局安装后** | `npm install -g miniagent` → 直接 `miniagent chat` |
| **本地开发** | `npm run dev` 或 `npx tsx src/cli.ts chat` |

### 功能演示

```bash
# 交互式聊天
miniagent chat -m qwen2:0.5b

# 列出所有会话
miniagent chat --list-sessions

# 单次执行
miniagent run "帮我创建一个 todo list"

# 查看所有工具
miniagent tools
```

## 💡 MiniAgent 独家创新：小模型增强方案

> **核心理念**："小模型 + 工程优化 = 可落地的代码助手"

MiniAgent 引入了 Claude Code 和 OpenCode 没有的独特功能，专门帮助小模型（7B 及以下）生成更好的代码：

### 1. 📦 代码预制库（Code Snippets Library）

小模型不擅长从零生成复杂代码，我们提供预制模板：

```
.miniagent/snippets/
├── typescript/
│   ├── react-component.tsx    # React 组件模板
│   ├── express-api.ts         # Express CRUD API
│   └── utils.ts               # TypeScript 工具类
└── python/
    ├── fastapi-app.py         # FastAPI 应用模板
    └── fastapi-router.py      # FastAPI 路由模板
```

### 2. 📚 文档缓存系统（Docs Cache）

不在项目中存储所有文档，而是首次访问时自动缓存：

```
.miniagent/docs/
├── index.yaml                 # 编程语言文档索引（15+ 语言）
── cache-config.yaml          # 缓存配置
── cache/                     # 缓存的文档
```

**工作流程**：
```
用户请求文档
     ↓
检查本地缓存
     ↓
缓存存在？──否──→ 在线获取 → 缓存到本地 → 返回内容
     ↓是
检查是否过期
     ↓
过期？──是──→ 更新缓存 → 返回内容
     ↓否
返回本地缓存（毫秒级响应！）
```

### 3. ✅ 生成后完整性检查

小模型容易生成不完整的代码，我们自动检查：

- **语法检查**：括号匹配、缩进一致性
- **导入检查**：所有导入存在且排序正确
- **结构检查**：export 语句、main 函数
- **安全检查**：硬编码密码、eval() 使用
- **完整性检查**：TODO/FIXME 检测

### 4. ▶️ 生成后自动运行

```yaml
run_strategy:
  immediate:    # 简单脚本立即运行
    - JavaScript/Node.js
    - Python 单文件
  delayed:      # 需要构建的代码延迟运行
    - TypeScript (需要编译)
    - Rust (需要 cargo build)
  manual:       # 风险操作手动确认
    - 数据库迁移
    - 删除操作
```

### 5. 🖨️ 完整日志注入

自动为生成的代码注入完善的日志：

```python
def process_data(data):
    logger.info(f"Processing {len(data)} items")
    logger.debug(f"Input: {data[:5]}...")
    # ... processing ...
    logger.info(f"Processed {len(result)} items")
    return result
```

## 🌐 Web UI

MiniAgent 提供 Web 界面，让你在浏览器中也可以使用！

### 启动 Web 服务器

```bash
# 基本用法
miniagent serve

# 自定义端口
miniagent serve --port 8080

# 设置密码保护
miniagent serve --ui-password mypassword

# 监听所有接口（局域网访问）
miniagent serve --host 0.0.0.0
```

### 访问 Web 界面

打开浏览器访问 `http://localhost:3000` 即可使用完整的 Web 聊天界面！

### 功能特性

- 💬 实时聊天界面
- 📱 移动端适配
- 📋 会话管理（创建/切换/删除）
- 🎨 深色主题，参考 OpenCode 设计
- ⚡ 快速建议按钮
- 🔄 自动刷新会话列表
