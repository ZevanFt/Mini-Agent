# 启动页输入框完整重构方案

## 核心设计

### 1. 统一背景色 #1e1e1e

启动页 Composer 渲染结构：
```
<Box flexDirection="column" backgroundColor={inputBg}>  ← 外层统一背景
  <Text>> 输入行1</Text>
  <Text></Text>            ← 行间距（仅多行时）
  <Text>> 输入行2</Text>
  <Text></Text>            ← 行间距
  <Text>  Build ● model</Text>  ← 状态行，同一背景
</Box>
<HintBar />              ← 提示栏，在背景外
```

关键：外层 `<Box>` 设置 `backgroundColor={inputBg}`，所有子元素继承同一背景色。

### 2. 行间距实现

使用 `flatMap` 遍历 `inputLines`，每行后插入空行：
```tsx
{inputLines.flatMap((line, i) => [
  <Text key={`line-${i}`} backgroundColor={inputBg}>{'> '}{displayText(line, i)}</Text>,
  // 行间距：最后一行后不加
  ...(i < inputLines.length - 1 ? [<Text key={`gap-${i}`} backgroundColor={inputBg}></Text>] : []),
])}
```

单行时无间距，多行时每行之间有一个空行。

### 3. 光标与输入框对齐

光标行在 Composer 内的偏移量：
- 每个输入行占 1 行
- 每个行间距占 1 行
- 当前行之前的总行数 = `cursorRow * 2`（行 + 间距）

MiniAgentTUI.tsx 光标计算：
```typescript
// 移除旧的 +1，使用新的偏移计算
cursorRowInComposer = cursorRow * 2;  // 当前行在Composer内的行号
cursorRow = topPadding + logoHeight + spacerHeight + cursorRowInComposer;
```

## 涉及文件

### Composer.tsx (启动页分支)
```tsx
if (position === 'start') {
  const innerW = textWidth + 1;
  const inputBg = TUI_THEME.inputBg;
  return (
    <Box width={textWidth + 2} flexDirection="column">
      <Box flexDirection="column" backgroundColor={inputBg}>
        {inputLines.flatMap((line, i) => {
          const displayText = line === '' && i === cursorRow && cursorCol === 0
            ? '输入消息... (输入 / 唤起命令)' : line;
          const truncated = truncateByWidth(displayText, textWidth - 2).text;
          return [
            <Text key={`line-${i}`} backgroundColor={inputBg}>
              {'> '}{truncated}
            </Text>,
            ...(i < inputLines.length - 1
              ? [<Text key={`gap-${i}`} backgroundColor={inputBg}>{' '.repeat(textWidth + 2)}</Text>]
              : []),
          ];
        })}
        <Text backgroundColor={inputBg}>
          {'  '}
          <Text color={TUI_THEME.accent}>{currentMode}</Text>
          {fillByWidth(`${TUI_GLYPHS.bullet} ${modelName}`, innerW - currentMode.length)}
        </Text>
      </Box>
      <HintBar w={textWidth + 2} />
    </Box>
  );
}
```

### MiniAgentTUI.tsx (光标计算)
```typescript
// 启动页光标
const cursorRowInComposer = state.cursorRow * 2;  // 行+间距
cursorRow = topPadding + logoHeight + spacerHeight + cursorRowInComposer;
```
