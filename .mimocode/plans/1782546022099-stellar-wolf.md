# 输入框重构：行间距 + 光标定位 + Logo 位置

## 三个改动

### 1. 行间距：文本行上下各一个空行

启动页 Composer 结构：
```
(空行 + #1e1e1e背景)      ← 上间距
> 输入消息... (输入 / 唤起命令)  ← 文本行
(空行 + #1e1e1e背景)      ← 下间距
Build ● qwen2.5-coder:3b  ← 状态行
HintBar                    ← 提示栏（无背景色）
```

每行用 `fillByWidth` 填满宽度，确保背景色覆盖整行。

### 2. Logo 上移 4 行

当前 Logo 居中，导致输入框偏下。将整体内容上移，但 logo 和输入框保持 3 行间距。

修改 `MiniAgentTUI.tsx` 的布局计算：
- 增大 `topPadding` 或减小 `justifyContent` 的居中偏移
- `spacerHeight` 保持 3

### 3. 光标定位：两套逻辑

**初始定位**（无输入时）：
- 直接定位到 `>` 后面
- `cursorRow = topPadding + logoHeight + spacerHeight + 1`（+1 是上间距空行）
- `cursorCol = centerX + 2`（`> ` 占 2 列）

**输入后定位**：
- `cursorCol = centerX + 2 + displayWidthBeforeCursor`（追加已输入文字宽度）
- `cursorRow` 不变（始终在 `>` 那行）

## 涉及文件
- `src/tui/primitives/Composer.tsx` — 行间距结构
- `src/tui/MiniAgentTUI.tsx` — 光标定位 + Logo 位置

## 验证
- `>` 行上下各有一个空行（带背景色）
- Logo 位置上移，输入框与 logo 保持 3 行
- 光标初始在 `>` 后面
- 输入文字后光标跟随
