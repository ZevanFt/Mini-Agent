# MiniAgent TUI 样式设计方案

## 一、整体布局

### 背景系统
- **底层**: 纯黑背景 (`#000000`)
- **星尘层**: Starfield 随机星星闪烁（已有）
- **皮肤字符层**: 随机装饰字符，但需要**禁区机制** — 避开所有 UI 元素区域

### 禁区机制设计
在 `index.ts` 的 `Starfield` 中增加 `exclusionZones: {x, y, width, height}[]`，每次渲染前清除禁区内的皮肤字符。UI 组件通过 `onResize` 回调上报自己的边界矩形。

```
┌──────────────────────────┬──────────────────┐
│  [用户消息]              │  Session Info    │
│                          │  Model: xxx      │
│  [AI 回复]               │  Tokens: xxx     │

│  > 输入框                │  128K / 6%       │
│  [Build] ● model        │                  │
│  ─────────────────       │                  │
│  提示信息                │                  │
├──────────────────────────┴──────────────────┤
│  ⚙ 设置  📁 文件  🤖 模式  💬 清空  📤 导出 │
└─────────────────────────────────────────────┘
```

### 元素清单

#### 左侧主区域
| 元素 | 说明 |
|------|------|
| 消息列表 | 用户消息 + AI 回复，支持滚动 |
| 思考过程 | 内联折叠，`<think>...endphp`，可展开/收起 |
| 输入框 | Composer 组件，支持多行 (Ctrl+Enter 换行) |
| 状态栏 | Build/Auto 模式 + 模型名 + token 用量 |
| 快捷键提示 | 与启动页一致 |

#### 右侧边栏
| 元素 | 说明 |
|------|------|
| Session 信息 | 会话 ID、模型名 |
| Token 用量 | 已用/总量百分比 |
| 文件上下文 | @ 添加的文件列表 |
| 子智能体 | $ 添加的子智能体状态 |

#### 底部工具栏
| 按钮 | 快捷键 | 功能 |
|------|--------|------|
| ⚙ 设置 | Ctrl+P | 打开设置面板 |
| 📁 文件 | @ | 添加文件到上下文 |
| 🤖 模式 | Tab | 切换 Build/Auto 模式 |
| 💬 清空 | Ctrl+Shift+D | 清空当前会话 |
| 📤 导出 | Ctrl+Shift+E | 导出对话 |

## 四、皮肤字符禁区

### 禁区定义
```typescript
interface ExclusionZone {
  x: number;
  y: number;
  width: number;
  height: number;
}
```

### 禁区区域
1. **启动页**: Logo 区域、输入框区域、状态栏区域
2. **对话页**: 消息列表区域、输入框区域、侧边栏区域、底部工具栏区域
3. **模态菜单**: 整个菜单边框内

### 实现方式
- Starfield 的 `render()` 方法增加 `exclude zones` 参数
- UI 组件通过 ref 或回调上报自身边界
- 每次渲染前计算禁区，跳过这些区域的字符
