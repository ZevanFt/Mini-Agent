# Slash 命令菜单样式重构

## 目标
对齐 MiMoCode 的 slash 菜单风格：无边框、背景色面板、选中项橙色高亮。

## 当前问题
1. `borderStyle="round"` 边框粗糙
2. 选中项只有文字变色，无背景高亮
3. 布局不够整洁

## 改动

### CommandRows.tsx
- 选中行：添加橙色背景 `backgroundColor={TUI_THEME.warning}`
- 选中文字：黑色 `color="black"`
- 非选中文字：暗灰色

### MiniAgentTUI.tsx（两处 slash 菜单）
- 移除 `borderStyle="round"` 和 `borderColor`
- 添加 `backgroundColor={TUI_THEME.panel}` 背景色
- 调整内边距

## 涉及文件
- `src/tui/primitives/CommandRows.tsx`
- `src/tui/MiniAgentTUI.tsx`（启动页 + 对话页各一处）

## 验证
- `bun run check` 类型检查
- 输入 `/` 弹出菜单，选中项有橙色背景
- 无边框，背景色覆盖完整
