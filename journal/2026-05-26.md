# 2026-05-26 — TUI 大重构：blessed → terminal-kit

## 背景
TUI 一直在 Windows Terminal 上崩溃/黑屏。`blessed` 最后一次提交 2017 年，对 Windows 支持极差。

## 改动记录

### 1. blessed 全家桶移除
- 删除 6 个旧文件：`screen.ts`、`input.ts`、`chat.ts`、`statusbar.ts`、`context.ts`、`types.ts`、`declarations.d.ts`
- 卸载依赖：`blessed`、`blessed-contrib`（约 600 行 → 0）
- 报错 `pkg.termWidth is not a function` — 这是 blessed 在 Windows 下的已知 bug

### 2. terminal-kit 替换（1 文件，~140 行）
- 新文件：`src/tui/index.ts`
- 使用 `term.fullscreen()` + `term.grabInput()` + `term.inputField()` 实现 REPL 风格界面
- 全屏模式下每次对话后 `fullRedraw()` 重绘屏幕，让 header 始终可见

### 3. 全局错误捕获
- CLI 层添加 `process.on('uncaughtException')` + `unhandledRejection`
- 将崩溃写入 `.miniagent/crash.log` 再打印 stderr
- 避免 TUI 崩溃时静默吞掉错误

### 4. Ctrl+C 不退出终端
- 新增 `waitForExit()` Promise，CLI handler `await` 它
- Ctrl+C 仅退出全屏模式（`grabInput(false)` + `fullscreen(false)`），不 `process.exit()`
- 进程可以继续运行，回到 shell 提示符

## 已知问题
- **Streaming 期间 header 会暂时滚走**：`fullRedraw()` 在消息完成后才恢复 header。流式输出时内容从当前光标处输出，会推着 header 向上滚动。
- **终端大小变化未处理**：resize 事件没有绑定
- **terminal-kit 依赖**：`package.json` 已有 `terminal-kit@3.1.2`
