## 1. 概述

这是 MiniAgent **最核心的流程**，理解了这个你就理解了 80% 的 Agent。

```
用户消息 → System Prompt → LLM → Tool 调用 → 结果 → LLM → 回复
```

## 2. 完整流程详解

### 2.1 步骤一: 接收用户消息

```typescript
// src/cli/commands/chat.ts
async function chat() {
  const userMessage = await getInput(); // 获取用户输入

  // 初始化会话
  const session = new Session();
  session.addMessage({ role: "user", content: userMessage });

  // 进入 QueryLoop
  await queryLoop.run(session);
}
```

---

### 2.2 步骤二: 构建 System Prompt

```typescript
// src/core/system-prompt.ts
class SystemPromptBuilder {
  async build(
    tools: Tool[],
    skills: Skill[],
    memory: MemoryManager,
    cwd: string
  ): Promise<string> {
    const parts: string[] = [];

    // 1. 基础角色设定
    parts.push(`你是 MiniAgent，一个有用的本地 AI 助手。`);

    // 2. 添加 Tool 描述
    parts.push(`你可以使用以下工具：`);
    for (const tool of tools) {
      parts.push(`- ${tool.name}: ${tool.description}`);
    }

    // 3. 添加 Skill 追加的 Prompt
    for (const skill of skills) {
      if (skill.systemPrompt) {
        parts.push(skill.systemPrompt);
      }
    }

    // 4. 添加 Memory 上下文
    const context = await memory.getContext();
    parts.push(`上下文：${context}`);

    // 5. 添加当前环境信息
    parts.push(`当前目录：${cwd}`);

    return parts.join("\n\n");
  }
}
```

---

### 2.3 步骤三: 调用 LLM (流式输出)

```typescript
// src/core/query-loop.ts
class QueryLoop {
  async run(session: Session): Promise<void> {
    const systemPrompt = await this.systemPromptBuilder.build(
      this.tools,
      this.activeSkills,
      this.memory,
      this.cwd
    );

    // 调用 LLM，流式输出
    for await (const chunk of this.llm.chat({
      messages: session.messages,
      systemPrompt: systemPrompt,
      stream: true
    })) {
      // 实时渲染到终端
      if (chunk.type === "content") {
        process.stdout.write(chunk.content);
      }

      // 检查 Tool 调用
      if (chunk.type === "tool_call") {
        await this.handleToolCall(chunk, session);
      }
    }
  }
}
```

---

### 2.4 步骤四: 解析响应 & 处理 Tool 调用

```typescript
async handleToolCall(toolCall: ToolCall, session: Session): Promise<void> {
  // 1. 查找对应的 Tool
  const tool = this.toolRegistry.get(toolCall.name);
  if (!tool) {
    throw new Error(`Unknown tool: ${toolCall.name}`);
  }

  // 2. 权限检查
  const allowed = await this.permissionSystem.check(
    tool.name,
    toolCall.parameters
  );

  if (!allowed) {
    const confirmation = await this.askUser(
      `是否允许使用 ${tool.name}?`
    );
    if (!confirmation) {
      session.addMessage({
        role: "tool",
        content: "用户拒绝了此操作"
      });
      return;
    }
  }

  // 3. 执行 Tool
  const result = await tool.execute(toolCall.parameters);

  // 4. 添加结果到会话
  session.addMessage({
    role: "tool",
    toolCallId: toolCall.id,
    content: JSON.stringify(result)
  });

  // 5. 递归回到步骤三，继续循环
  await this.run(session);
}
```

---

### 2.5 步骤五: 结束循环 (最终回复)

```typescript
// 当 LLM 不再调用 Tool，只返回纯文本时循环结束
if (chunk.type === "content" && !chunk.toolCall) {
  // 保存到记忆
  await this.memory.extract(session);

  // 清理并结束
  return;
}
```

## 4. 关键实现细节

### 4.1 流式输出

```typescript
// Ollama 的流式响应处理
for await (const resp of await ollama.chat({
  model: "qwen2:0.5b",
  messages,
  stream: true
})) {
  if (resp.message?.content) {
    // 实时输出 token
    process.stdout.write(resp.message.content);
  }

  // 收集完整响应
  fullResponse += resp.message?.content || "";
}
```

### 4.2 无限循环保护

```typescript
// 防止无限循环
const maxIterations = 10;
let currentIteration = 0;

while (currentIteration < maxIterations) {
  currentIteration++;

  // ... 执行逻辑

  if (currentIteration >= maxIterations) {
    throw new Error("达到最大迭代次数");
  }
}
```

## 5. 学习要点

### 5.1 理解这个流程

1. **这是 Agent 的核心**: 所有 Agent 框架本质上都是这个流程的变体
2. **循环是关键**: Agent 通过 Tool 调用和结果反馈不断迭代
3. **流式输出优先**: 用户体验好
4. **记忆很重要**: 但也要注意上下文限制

### 5.2 调试技巧

```typescript
// 打印当前会话消息
console.log("Current messages:", session.messages);

// 打印 System Prompt
console.log("System prompt:", systemPrompt);

// 打印 Tool 调用日志
console.log("Tool call:", toolCall);
```
