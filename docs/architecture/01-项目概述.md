## 1. 项目定位

### 1.1 MiniAgent 是什么

```
MiniAgent = 极简 + 本地 + 可学习 + 开源
```

MiniAgent 是一个**面向个人开发者的轻量级本地 Agent 框架**。

- **零门槛**: 不需要 API Key，本地运行
- **可学习**: 代码注释完善，适合学习 Agent 开发
- **功能全**: 对齐 Claude Code 的核心功能
- **可扩展**: 支持自定义 Tool/Skill/MCP

### 1.2 解决的痛点

| 痛点 | MiniAgent 方案 |
|------|----------------|
| 想玩 Agent 但没 API 预算 | 本地 Ollama 驱动 |
| 大框架太复杂学不懂 | 代码精简、注释详细 |
| 低配电脑跑不起来 | 支持 0.5B 级模型 |
| 想加功能但改不动 | 模块化设计，易扩展 |

### 1.3 目标用户

- 🧑‍💻 **独立开发者**: 做个人项目的 AI 助手
- 🎓 **学习者**: 想学习 Agent 开发的初学者
- 🔧 **极客**: 喜欢在终端玩各种工具的人
- 💰 **预算有限者**: 不想为 API 花钱

## 3. 技术选型

### 3.1 为什么选这个技术栈

| 技术 | 理由 |
|------|------|
| **TypeScript** | 前端友好，类型安全，IDE 提示好 |
| **Bun** | 启动快，Node 兼容，性能好 |
| **Ollama** | 本地模型生态好，简单易用 |
| **Ink** | React 写终端 UI，有趣 |
