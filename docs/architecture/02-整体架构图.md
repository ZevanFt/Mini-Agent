## 4. 学习要点

### 4.1 核心设计原则

1. **单一职责**: 每个模块只做一件事
2. **依赖注入**: 组件之间通过接口交互
3. **可扩展性**: 新增 Tool/Skill 不需要改核心代码
4. **安全优先**: 所有操作都有权限检查

### 4.2 关键设计决策

| 决策 | 理由 |
|------|------|
| 三层 Memory | 平衡上下文限制与记忆能力 |
| 独立 Skill 层 | Skill 可以复用，独立于 Agent |
| 流式输出优先 | 提升用户体验 |
| 本地优先 | 隐私保护 + 零成本 |
