## 1. 概述

记忆系统是 Agent 的**大脑**，它让 Agent 能:
- 记住对话上下文
- 记住用户偏好
- 学习长期知识
- 避免重复提问

## 2. 三层架构详解

### 2.1 第一层: Working Memory (工作记忆)

```
容量: ~2K tokens (当前对话)
生命周期: 单次对话
特点: 快、直接访问

职责:
├─ 最近 5-10 条消息
├─ 当前任务状态
└─ 临时变量
```

### 2.2 第二层: Session Memory (会话记忆)

```
容量: ~10K tokens (当前项目)
生命周期: 项目生命周期
存储: MEMORY.md (纯文本)

职责:
├─ 项目结构摘要
├─ 最近重要决策
├─ 未完成任务
└─ 用户偏好
```

### 2.3 第三层: Long-term Memory (长期记忆)

```
容量: 无限
生命周期: 永久
存储: ~/.miniagent/memory/ (JSON/Vector DB)

职责:
├─ 跨项目知识
├─ 用户习惯
├─ 错误教训
└─ 常用代码片段
```

## 4. 代码结构

### 4.1 MemoryManager 主类

```typescript
// src/memory/index.ts
interface MemoryRequest {
  query: string;
  maxTokens: number;
}

class MemoryManager {
  private workingMemory: WorkingMemory;
  private sessionMemory: SessionMemory;
  private longTermMemory: LongTermMemory;

  constructor(options: MemoryOptions) {
    this.workingMemory = new WorkingMemory(options.workingMemSize);
    this.sessionMemory = new SessionMemory(options.projectPath);
    this.longTermMemory = new LongTermMemory(options.userPath);
  }

  async getContext(request: MemoryRequest): Promise<string> {
    const parts: string[] = [];

    // 1. 优先添加工作记忆
    const working = await this.workingMemory.get(request.maxTokens * 0.4);
    if (working) parts.push(`## 工作记忆\n${working}`);

    // 2. 添加会话记忆
    const session = await this.sessionMemory.get(request.maxTokens * 0.3);
    if (session) parts.push(`## 会话记忆\n${session}`);

    // 3. 如果有查询，从长期记忆搜索相关内容
    if (request.query) {
      const relevant = await this.longTermMemory.search(
        request.query,
        request.maxTokens * 0.3
      );
      if (relevant) parts.push(`## 相关记忆\n${relevant}`);
    }

    return parts.join("\n\n---\n\n");
  }

  // 从当前对话提取重要信息保存
  async extract(session: Session): Promise<void> {
    const extraction = await this.llm.extract(`
      从以下对话中提取关键信息:
      ${session.messages.map(m => `${m.role}: ${m.content}`).join("\n")}

      提取以下内容，JSON 格式:
      {
        "projectUpdates": "...",
        "userPreferences": "...",
        "unfinishedTasks": [...],
        "keyDecisions": [...]
      }
    `);

    // 更新会话记忆
    await this.sessionMemory.update(extraction);

    // 更新长期记忆（重要的跨项目知识）
    if (extraction.crossProject) {
      await this.longTermMemory.store(extraction.crossProject);
    }
  }
}
```

### 4.2 WorkingMemory 实现

```typescript
// src/memory/working-memory.ts
class WorkingMemory {
  private maxTokens: number;
  private messages: Message[] = [];

  constructor(maxTokens: number) {
    this.maxTokens = maxTokens;
  }

  addMessage(message: Message): void {
    this.messages.push(message);
    this.truncateIfNeeded();
  }

  async get(maxTokens: number): Promise<string> {
    const messages = this.truncate(this.messages, maxTokens);
    return messages.map(m => `${m.role}: ${m.content}`).join("\n");
  }

  private truncateIfNeeded(): void {
    let total = this.countTokens(this.messages);
    while (total > this.maxTokens && this.messages.length > 1) {
      this.messages.shift();
      total = this.countTokens(this.messages);
    }
  }
}
```

### 4.3 SessionMemory 实现

```typescript
// src/memory/session-memory.ts
class SessionMemory {
  private memoryPath: string;
  private content: string = "";

  constructor(projectPath: string) {
    this.memoryPath = path.join(projectPath, ".miniagent", "MEMORY.md");
    this.load();
  }

  async update(data: any): Promise<void> {
    // 更新 MEMORY.md 文件
    const lines = this.content.split("\n");

    // 添加/更新各个部分
    if (data.projectUpdates) {
      lines.push(`\n## 项目更新\n${data.projectUpdates}`);
    }

    this.content = lines.join("\n");
    this.save();
  }

  async get(maxTokens: number): Promise<string> {
    if (this.countTokens(this.content) <= maxTokens) {
      return this.content;
    }

    // 超过限制时摘要化
    return await this.llm.summarize(this.content, maxTokens);
  }

  private load(): void {
    if (existsSync(this.memoryPath)) {
      this.content = readFileSync(this.memoryPath, "utf-8");
    }
  }

  private save(): void {
    ensureDirSync(path.dirname(this.memoryPath));
    writeFileSync(this.memoryPath, this.content);
  }
}
```

## 6. 学习要点

### 6.1 为什么是三层

| 层 | 权衡 |
|----|------|
| Working Memory | 快但小，当前对话 |
| Session Memory | 中速中等，当前项目 |
| Long-term Memory | 慢但大，持久存储 |

### 6.2 记忆提取策略

1. **最近优先**: 保留最新消息
2. **重要性优先**: 重要信息保留在 Session Memory
3. **相关性优先**: 用搜索从 Long-term Memory 找相关内容
