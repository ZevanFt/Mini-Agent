## 1. 概述

权限系统是 MiniAgent 的**安全卫士**，负责:
- 阻止危险操作
- 控制 Tool 访问
- 实现细粒度权限控制

## 2. 权限模型

### 2.1 三级权限

```
1. 全局规则 (高优先级)
   └─ "永远禁止: rm -rf /"

2. 项目级规则
   └─ "项目 A 允许: git *"

3. 用户确认 (最低优先级)
   └─ "不确定时询问用户"
```

### 2.2 权限规则格式

```typescript
interface PermissionRule {
  tool: string;
  pattern?: string;       // 正则匹配参数
  action: "allow" | "deny" | "ask";
}

// 示例配置 (.openagent.json)
{
  "permissions": {
    "askOnFirstUse": true,
    "rules": [
      {
        "tool": "bash",
        "pattern": "git *",
        "action": "allow"
      },
      {
        "tool": "bash",
        "pattern": "rm *",
        "action": "ask"
      },
      {
        "tool": "bash",
        "pattern": "rm -rf",
        "action": "deny"
      },
      {
        "tool": "file_write",
        "action": "ask"
      }
    ]
  }
}
```

## 3. 代码结构

```typescript
// src/tools/permissions.ts
interface PermissionCheckResult {
  allowed: boolean;
  reason: string;
}

class PermissionSystem {
  private globalRules: PermissionRule[];
  private projectRules: PermissionRule[];
  private askOnFirstUse: boolean;
  private usedTools: Set<string> = new Set();

  constructor(options: PermissionOptions) {
    this.globalRules = options.globalRules || [];
    this.projectRules = options.projectRules || [];
    this.askOnFirstUse = options.askOnFirstUse ?? true;
  }

  async check(toolName: string, params: any): Promise<PermissionCheckResult> {
    // 1. 先检查全局规则
    for (const rule of this.globalRules) {
      if (this.matchRule(rule, toolName, params)) {
        if (rule.action === "deny") {
          return { allowed: false, reason: "被全局规则禁止" };
        }
        if (rule.action === "allow") {
          return { allowed: true, reason: "被全局规则允许" };
        }
        if (rule.action === "ask") {
          return { allowed: false, reason: "需要用户确认" };
        }
      }
    }

    // 2. 再检查项目规则
    for (const rule of this.projectRules) {
      if (this.matchRule(rule, toolName, params)) {
        if (rule.action === "deny") {
          return { allowed: false, reason: "被项目规则禁止" };
        }
        if (rule.action === "allow") {
          return { allowed: true, reason: "被项目规则允许" };
        }
        if (rule.action === "ask") {
          return { allowed: false, reason: "需要用户确认" };
        }
      }
    }

    // 3. 首次使用检查
    if (this.askOnFirstUse && !this.usedTools.has(toolName)) {
      this.usedTools.add(toolName);
      return { allowed: false, reason: "首次使用需要确认" };
    }

    // 4. 默认放行
    return { allowed: true, reason: "默认允许" };
  }

  private matchRule(rule: PermissionRule, toolName: string, params: any): boolean {
    if (rule.tool !== "*" && rule.tool !== toolName) {
      return false;
    }

    if (rule.pattern) {
      const paramStr = JSON.stringify(params);
      const regex = new RegExp(rule.pattern);
      return regex.test(paramStr);
    }

    return true;
  }
}
```

## 4. 内置安全检查

```typescript
// src/tools/security.ts
const DANGEROUS_PATTERNS = [
  // 删除系统文件
  /rm -rf \//,
  /rm -rf \*$/,

  // 危险的命令管道
  /\|\s*bash/,
  /\|\s*sh/,
  /curl.*\|\s*bash/,
  /wget.*\|\s*bash/,

  // 权限提升
  /^sudo\s/,

  // 破坏性操作
  /mkfs/,
  /dd if=/,

  // 网络攻击
  /nc.*-e/,
  /nc.*-c/,

  // Fork Bomb
  /:\(\)\s*\{.*:\|:&/,
  /fork\s*\(\s*\)\s*\{/
];

function hasDangerousPattern(command: string): boolean {
  for (const pattern of DANGEROUS_PATTERNS) {
    if (pattern.test(command)) {
      return true;
    }
  }
  return false;
}

const SENSITIVE_FILES = [
  /\.env$/,
  /\.pem$/,
  /\.key$/,
  /id_rsa/,
  /id_dsa/,
  /passwd/,
  /shadow/,
  /\.aws/,
  /\.ssh/
];

function isSensitiveFile(path: string): boolean {
  for (const pattern of SENSITIVE_FILES) {
    if (pattern.test(path)) {
      return true;
    }
  }
  return false;
}
```

## 5. 学习要点

### 5.1 安全原则

1. **默认拒绝**: 不知道的操作先拒绝
2. **最小权限**: 只给必要的权限
3. **用户确认**: 危险操作都要问用户
4. **日志记录**: 所有操作都要留痕

### 5.2 常见危险

| 操作 | 风险 | 处理 |
|------|------|------|
| `rm -rf /` | 删除系统 | 直接禁止 |
| `curl | bash` | 执行未知代码 | 禁止或询问 |
| 写密码文件 | 泄露密码 | 禁止 |
| `sudo` | 权限提升 | 询问 |
